Eve's Breakpoint

Pauses the simulation when its input goes from low to high, within one tick at any simulation speed. Wire it to a halt signal, a flag, or any condition you want to catch.

Pin

One input peg on top. No outputs.

Behaviour

  • Edge-triggered: it pauses on the low-to-high transition only, and won't pause again while the signal stays high.
  • The simulation stays paused until you resume it: the pause/play button, or simulation.resume in the console. Single-stepping still works while paused.
  • It logs Breakpoint hit! to the console.

Pausing within one tick

Logic World runs ticks in catch-up batches: each frame runs as many ticks as needed to keep up with the speed you set. On its own it checks the pause only once per batch, so at high speeds a pause from inside a tick would come many ticks late. The mod patches the simulation loop (with HarmonyForLogicWorld) to check again after every tick, so the breakpoint stops the simulation on the very tick its input rose, whatever the speed.
