Eve's Microcode ROM

32-bit words at 16-bit addresses: a control store for microcoded CPUs, one word per address, writable from the circuit.

Pins

Back face: inputs Front face: outputs

Each peg is drawn at its x position in the block's prefab, from x = 0 on the left. Small grey numbers are the peg indexes in the code; the upper row is y = 1.5, the lower y = 0.5. Here the most significant bit is on the left on both faces, and peg 0 of the outputs is bit 31.

PegsNameWhat it does
in 0WERising edge: the word on D0–D31 is written at the address.
in 1–16A15–A0The word address (peg 1 is bit 15, peg 16 bit 0).
in 17–48D31–D0The word to write (peg 17 is bit 31, peg 48 bit 0).
out 0–31Q31–Q0The word at the address, always (peg 0 is bit 31).

Behaviour

  • Reading is continuous, like Eve's RAM: the outputs follow the address.
  • Writing takes one rising edge of WE.
  • Size: 65,536 words (256 KB). The editor can load the first 16,384 words (64 KB of bytes); the circuit can write all.
  • Byte order: word n is bytes 4n to 4n+3, least significant first.

Contents

The same editor as the RAM (press X). Addresses there count bytes: word n starts at @0x 4n. A token of 8 hex digits fills one word, for example:

@0x0E40            // byte 0xE40 = word 0x390
0x00005000 0x00000080

A microcode generator can write its output in this format and the block loads it with @file.
