Eve's Components

Custom components for Logic World, made for building CPUs: memory with an in-game editor, a microcode ROM, a network port, and debugging help.

Eve's RAM

64 KB, byte-wide, 16 address bits. Loaded from the editor or a file.

 Eve's RAM (32-bit)

32-bit address, the LW32 CPU block's bus: 1, 2 or 4 bytes, answered in one tick.

 Eve's Disk

16 MB on the LW32 CPU block's bus, kept in the save's bins/disk.bin.

 Eve's Microcode ROM

32-bit words, 16 address bits. For control words.

 Eve's Network Port

A byte pipe between the circuit and a TCP connection: terminals, web pages, networking.

 Eve's LW32 CPU

The LW32 CPU as one block on your bus: runs the same programs, a few times faster. In progress.

 Normally-Closed Relay

Connects two pegs unless its control is high.

 Eve's Breakpoint

Pauses the simulation within one tick of a rising edge.

 The ROM editor

Press X at a RAM or ROM: hex and binary bytes, addresses, files.

Installing

  1. Copy the mod's folder (EVE_Components) into Logic World/GameData.
  2. Install its dependencies the same way: EccsLogicWorldAPI and HarmonyForLogicWorld.
  3. Start Logic World. It compiles the mod at start-up, so restart it after updating the mod.

The components are in the build menu under Eve's Components, in three groups: Memory (RAM, Microcode ROM), Other (Network Port, LW32 CPU, Normally-Closed Relay) and Debug (Breakpoint).

Conventions

  • Inputs are on the back face, outputs on the front face of the wide blocks.
  • Edges: writes happen on the rising edge of a write pin. Reads are always live: the outputs follow the address, without a read pin.
  • Bit order in the drawings: each pin page shows every peg at its position in the block, with its name and its index in the code.
  • Saving: memory blocks keep the text you typed in the editor with the world, not a copy of the bytes. Files named with @file are read again every time the world loads (the editor).
