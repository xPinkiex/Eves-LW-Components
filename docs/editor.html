The ROM editor

Press X while looking at Eve's RAM or Eve's Microcode ROM to fill it: bytes typed or pasted, addresses, and files from the save.

Syntax

TokenMeaning
0xFFHex bytes, up to 8 digits. More than 2 digits are 16-bit words stored least significant byte first: 0x00FF → FF 00, 0xDEADBEEF → EF BE AD DE. An odd digit count is padded on the left.
0b11001000Binary, up to 16 bits (two bytes, the same order).
@0xADDRContinue at this byte address (up to 4 hex digits).
@file PATHLoad a file here (@file "PATH" if it has spaces).
// textA comment, to the end of the line.
# textAlso a comment.

Bytes go one after another from address 0, or from the last @0x. The contents end at the highest byte written, so the order of the blocks doesn't matter.

0x01 0b11001000 0xFF      // three bytes at 0
@0x0100
0x1234                    // 34 12 at 0x100

Files: @file

For programs too big to paste. Put the file in the save's bins folder, Logic World/saves/<save>/bins, and write:

@file kernel.bin
@0x8000 @file data.bin      // more files, or bytes, elsewhere
  • .bin files are copied in as raw bytes.
  • Any other file is read as text in the editor's format, and may itself use @0x and @file (up to 8 levels).
  • After a file, loading continues right after its last byte.
  • Paths: relative ones are looked up in the save's bins folder, or in Logic World/roms if the server can't find the save. Absolute paths work too.
  • When files are read: on Apply and again every time the world loads, because the world keeps only the editor text, and on Eve's RAM (32-bit) at each rising edge of its RELOAD peg. After rebuilding a program, press Apply, pulse RELOAD or reload the world. The editor shows the server's answer: the byte count, or an error.
  • A missing file leaves the block empty when the world loads. The server log says why, and the text is kept.
  • How much a block takes: Eve's RAM and the microcode ROM 64 KB, so one file fills at most one block; Eve's RAM (32-bit) up to 1 GiB from address 0.

Buttons

ApplyParse the text and load it into the block.
ClearEmpty the block and the text.
SaveStore the current text with the world. The circuit's writes are dropped.
RestoreGo back to the last saved state.

The key is X by default; change it under Controls, "Mod: Eve's Components".
